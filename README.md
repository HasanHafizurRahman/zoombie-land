# Zombie Land

A first-person zombie shooter set in a war-ruined alpine valley, running directly in the browser on Three.js (WebGL2).

Every visual asset is generated by code or loaded from clean, optimized assets: the eroded mountain range, the valley, the ruined village with its church and enterable houses, the broken bridge, the river, grass and trees, weapons with animated arms, multiple infected types, and all PBR texture sets.

The game is packaged as a **pure static HTML5 web application**—requiring zero build tools, zero npm packages, and zero compilation steps to play or deploy.

---

## Run It

Because the game is static HTML, you can run it with any local static HTTP server:

### Option 1: Python
```bash
python -m http.server 5183
```

### Option 2: Node (`npx serve`)
```bash
npx serve . -l 5183
```

### Option 3: VS Code / Live Server
Right-click `index.html` and select **Open with Live Server**.

Then open **http://127.0.0.1:5183** in your browser. A GPU with WebGL2 support is required; the game includes four quality presets in Settings.

You can also deploy this repository directly to **GitHub Pages**, **Netlify**, **Cloudflare Pages**, or **Itch.io** by hosting the folder as static files.

## Game Modes

- **Survival**: Hold the village against escalating waves of infected. Waves mix walkers, runner packs, and brute escorts; a boss arrives every fifth wave. Each cleared wave drops a supply crate with ammunition and bandages.
- **Operation**: A run-based mode with permanent progression. A helicopter drops you at a landing zone, waves escalate without end, and kills earn salvage. Extract via helicopter to bank everything; death ends the run and banks a partial share. Between runs, spend salvage at the **Base** on weapon upgrades, body stats, abilities, and run modifiers. Progress saves locally in your browser (`localStorage`).

## Controls

| Action | Input |
|---|---|
| Move / look | W A S D / Mouse |
| Fire / aim | Left / Right Mouse Button |
| Reload | R |
| Next weapon / direct | Q / 1 2 3 4 5 |
| Sprint / jump | Shift / Space |
| Crouch / prone | Ctrl or C / Z (toggle) |
| Dodge roll | V |
| Use bandage | H |
| Interact | F |
| Abilities (Operation mode) | G, 4, 5 |
| Pause | Esc |

*Health regenerates only to the top of the current segment; bandages do the rest. Falls above 3.5 m cause damage; rolling upon landing cuts damage in half.*

## Phones and Tablets

The game runs in modern mobile browsers in landscape orientation.

* **Touch Controls:** Left thumb moves (drag outward to sprint); right thumb looks/turns; large button fires; dedicated buttons for aim, reload, crouch/prone, bandage, and weapon switching.
* **Fullscreen:** Tap anywhere to enter fullscreen and lock landscape.
* **Mobile Tier:** The game automatically detects mobile devices and switches to the optimized Phone tier, loading compressed assets from `assets/m/` and dynamically adjusting render resolution to maintain a steady 30 FPS.
